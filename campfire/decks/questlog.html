  2. Databasewith login. Everybody only sees what they may see.

How it's built: a web app on GitHub Pages talks to a database with login, Supabase. Row-level security means everybody only sees what they may see. An MCP server with 68 tools lets an AI assistant log time or ask "where is it burning?", with exactly the rights of the person asking. About seventy test files, and every change passes checks, a security audit and browser tests before it goes live.
