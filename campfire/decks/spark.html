Model 1

It predicts the next word

A very well-read autocomplete. It doesn't know, it continues.

That's why it can sound confident and still be wrong.

The campfire is …

  • warm
  • bright
  • dying
  • hungry
  • purple
An LLM is a very well-read autocomplete: it doesn't know, it continues, one likely word after another. That's why it can sound confident and still be wrong. In the Token Oracle module you type the start of a sentence and watch the candidates burn as pixel bars. Turn up the temperature and the fire gets wild.

Model 2 · The context window

It only sees the circle of light

  • your prompt
  • your files
  • the chat so far
  • everything else: it doesn't exist

Long chats push old things into the dark. Good projects keep their memory in files.

The context window is the campfire circle. Whatever is in the light, your prompt, your files, the chat so far, the model can use; everything in the dark doesn't exist for it. Long chats push old stuff into the dark, which is why good projects keep their memory in files. The Context Circle module shows it: when the circle is full, the oldest messages step back into the dark.

Model 3

With tools, it can act

Give a chat model a search engine, a code runner, GitHub or your whiteboard, and it becomes an agent.

  1. PlanIt breaks the task into steps.
  2. DoIt uses the tools.
  3. CheckIt looks at the result.
Third picture: give the model tools and it stops just talking. With a search engine, a code runner, GitHub or your whiteboard, a chat model becomes an agent. It plans, it does, it checks.
