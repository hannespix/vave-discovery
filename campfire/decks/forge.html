Station five: the forge. This is the professional toolchain, in designer language. Agents, tests and review are what make it reliable.

05 · What

GitHub in six words

  • Repository

    A project folder with a perfect memory.

  • Commit

    A save point with a note.

  • Branch

    A parallel sketch. The main version stays safe.

  • Pull request

    A review round before it goes live: robots, a critic agent, or you.

  • Actions

    Robots that test and publish on every change.

  • Pages

    Free hosting. Public links for public things.

GitHub in six words. A repository is a project folder with a perfect memory; a commit is a save point with a note. A branch is a parallel sketch, a pull request is a review round, Actions are robots, and Pages is free public hosting — public links for public things, never a client secret, to the client. The Git Time Machine module lets you play with it.

05 · How

A team, not one chat

  • Builder

    Builds exactly one task.

  • Critic

    Judges how it looks and works.

  • Red team

    Tries to prove it wrong.

  • Gatekeeper

    Checks if a milestone is really reached.

Not one chat, but a team of agents: a builder, a critic, a red team and a gatekeeper. Each has exactly one job. In the VAVE discovery repo they live in the agents folder.

Agents propose,
humans decide.

And the rule above all of them: agents propose, humans decide. The big decisions, like what we build and what we leave out, are written down by a person, not by an agent.

05 · Trust

Trust comes from checks, not from vibes

  • Quick robots

    Every pull request: build and checks in about a minute.

  • Big suites

    Browser tests and accessibility checks, at night or before a release.

  • A human

    Looks at the live result. Taste is not automated.

How do I trust code I didn't type? Not from vibes, from checks. Quick robots on every pull request, about a minute. The big browser and accessibility suites run at night or before a release. And a human looks at the live result. Honest version: the robots catch breakage, not bad taste.
