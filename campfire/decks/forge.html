05 · What

GitHub in six words

  • Repository

    A project folder with a perfect memory.

  • Commit

    A save point with a note.

  • Branch

    A parallel sketch. The main version stays safe.

  • Pull request

    A critique round before anything goes live.

  • Actions

    Robots that test and publish on every change.

  • Pages

    Free hosting: the link you send to the client.

GitHub in six words. A repository is a project folder with a perfect memory; a commit is a save point with a note. A branch is a parallel sketch, a pull request is a critique round, Actions are robots, and Pages is the link you send to the client. The Git Time Machine module lets you play with it.

05 · How

A team, not one chat

  • Builder

    Builds exactly one task.

  • Critic

    Judges how it looks and works.

  • Red team

    Tries to prove it wrong.

  • Gatekeeper

    Checks if a milestone is really reached.

Not one chat, but a team of agents: a builder, a critic, a red team and a gatekeeper. Each has exactly one job. In the VAVE discovery repo they live in the agents folder.

Agents propose,
humans decide.

And the rule above all of them: agents propose, humans decide. No milestone counts as passed until a person has written the decision down.

How do I trust code I didn't type? Not from vibes, from checks. Automated browser tests, accessibility audits with thirteen screens and zero findings, and a test suite that runs before every release.
